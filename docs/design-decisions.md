# 食間設計決策

2026-09-10，使用者已確認以下方向並授權實作。

- 餐飲品牌的食慾與精緻構圖，首屏直接選餐；取代大轉盤。
- 菜單卡揭曉、強烈電影感動態。
- 正常自由捲動，局部影像與文字演出，不鎖住捲動進度。
- 避免模板式英文標語、印章與裝飾堆疊。不添加假光暈或多方向陰影。
- 首屏直接選餐，不放照片或插圖。店家資料不配假造餐點照片。

## 動態規格

首次揭曉約 2.6 秒，再次約 1.6 秒；手機改為約 1.8／1.2 秒。候選卡先過場，中選菜單停住再打開詳情。資料池在整輪中固定。鍵盤、單一選項及減少動態模式直接交付結果。動畫不可用或失敗仍須交付結果。不使用光暈、紙屑或英文標語。

標題分行進場。詳情進場 280ms、退出 180ms，原生 dialog 保留 Escape 與焦點管理。

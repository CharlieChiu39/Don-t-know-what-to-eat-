# 食間改版：審查與驗收紀錄

## 基準與進度盤點

基準：`origin/main` 的 `8932b06`。原版已有 81 間餐廳、餐別／預算／料理篩選、轉盤、封鎖清單與結果分享。多人房間僅有 `js/room.js` 草稿，未載入，README 僅有名稱。

原版可重現的邏輯問題：未知時間視為營業中；跨夜只看當日；連續轉動的角度會累積前次落點偏移；轉動時可換清單；全不勾選時舊選項仍保留。本次以共用篩選、三態營業判斷、固定本輪選項及正確角度計算處理。

## 最終設計

品牌「食間」，定位為中正大學的日常選餐工具。依使用者指定，讀取 dessertProject 的現行 `app/globals.css`、`HeroScene.module.css`、`ShowcaseSection.module.css` 與 `CLAUDE.md` 作為視覺參考。主要採用紙色 `#F3EEE3`、柿色 `#AD5330`、深褐色 `#241D16`、在地宋體、大標與細線；沒有複製 dessertProject 的程式或素材。

保留靜態網站部署。移除執行期 Tailwind／Google Fonts 依賴，字型子集與授權置於 `assets/fonts/`。SVG 碗筷與品牌字標為本次原創。
